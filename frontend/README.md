# The Grand Prix Predictor — Frontend

React 18 + Vite 6 + Tailwind CSS 4 + Lucide React + Recharts.

## Run locally

1. Start FastAPI from the project root with `python run.py`.
2. In a second terminal, run `cd frontend`, `npm install`, and `npm run dev`.
3. Open `http://127.0.0.1:5173`.

Vite proxies `/api` requests to FastAPI at `127.0.0.1:8000`. `npm run build` writes to `../app/static/`.

## Frontend design

The landing page is a long-form motorsport editorial experience. Its top branding/navigation row is intentionally omitted; the hero retains the title “THE GRAND PRIX PREDICTOR” without a trailing full stop. It includes the user-supplied `public/models/f1-car.glb`, a graphite PBR material override, continuous model rotation/floating movement and illustrative airflow / pressure-style overlays. These overlays are not generated by a CFD solver and must not be presented as measured aerodynamic data.

The analytics workspace uses horizontal navigation and keeps the existing API-driven Race Centre, Pole Predictor, Race Predictor, Practice Intelligence, Constructor Intelligence, Driver Intelligence, Circuit Intelligence, Season Standings and Model Lab screens. The dashboard and feature screens use a restrained, image-led editorial layout. Country flags are shown where a country can be mapped reliably from the local data.

## Image and runtime requirements

Formula One photographs are displayed from Wikimedia Commons thumbnail URLs, with source/licence links shown in the interface and full credits in the repository-root `CREDITS.md`. The archive does not bundle these images locally; an internet connection is required to fetch them. Country flags load from FlagCDN. Google Fonts and the `<model-viewer>` 4.x browser runtime are also loaded remotely. The supplied GLB itself is included under `public/models/`.

For a production build, run `npm run build` from this directory and restart FastAPI so it serves the generated static assets and `/models` path.
